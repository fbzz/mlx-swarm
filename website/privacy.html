MLX Swarm Product Privacy

Privacy

This static website does not include analytics, ads, or a cookie banner, because it does not set tracking cookies.

The setup form is validated in your browser. Nothing from that form is uploaded to MLX Swarm servers. If you continue, GitHub receives whatever you choose to file as an issue under GitHub privacy terms.

The cockpit and local runtime bind to localhost. Prompts, patches, and session files stay on the machine that runs MLX Swarm unless you copy a commander handoff to a frontier host.

Questions: open an issue at github.com/fbzz/mlx-swarm.
